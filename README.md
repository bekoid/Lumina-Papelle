# Lumina Papelle 🌸✨
> **Estetik Dijital Kırtasiye & Not Alma Stüdyosu**  
> *Aesthetic Digital Stationery & Notebook Studio*

Lumina Papelle, analog kağıt defterlerin dokusal zarafetini modern dijital üretkenlikle birleştiren, %100 yerel ve gizlilik odaklı bir masaüstü not alma stüdyosudur.

---

### 🎨 Öne Çıkan Özellikler
- **11 Pastel & Minimalist Atmosfer:** Açık & Koyu modlar, kadife ve ipek tonlar, saf huzur.
- **Gerçekçi Kağıt Deneyimi:** Çizgili, Kareli, Noktalı (Bullet), Düz, Cornell Metodu ve Haftalık Ajanda şablonları.
- **Özgür Sayfa Renkleri:** Gece kağıdı, tebeşir beyazı, fildişi, matcha, lavanta ve gök mavisi tonları.
- **19 Seçkin Yazı Tipi:** El yazısı, modern sans-serif ve klasik serif tipografi koleksiyonu.
- **Akıllı Araç Kutusu:** Dolma kalem mürekkepleri, fosforlu kalem, kurşun kalem, cetvel, yapışkan notlar, çıkartmalar ve süsleme bantları.
- **Sıfır Veri Kaybı (Zero Data Loss):** Tuş vuruşu düzeyinde anlık yerel taslak ve otomatik kurtarma mekanizması.
- **Akustik Odak Sesleri:** Yağmur, kahve dükkanı, şömine, gece ormanı ve fırtına sentezleyicisi (tamamen çevrimdışı).
- **%100 Gizlilik & Güvenlik:** Verileriniz hiçbir sunucuya gitmez, bilgisayarınızda IndexedDB kasasında saklanır.

### 🛠️ Geliştirme & Derleme

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Web derlemesi oluşturun
npm run build

# Bağımsız Windows Portable EXE üretin
npm run build:exe
```
